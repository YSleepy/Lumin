# 数学基础

## 坐标系

Lumin 使用**右手坐标系**：
- **X轴**：向右
- **Y轴**：向上
- **Z轴**：从屏幕向外（观察者方向）

面对 Z 轴正方向时，**逆时针**旋转为正。

## 向量 (Vector)

向量表示方向和大小。

### 二维向量 LVec2

```
LVec2 v = {x, y}
```

操作：
- `+`、`-`：向量加减
- `*`、`/`：标量乘除
- `Dot(a, b)`：点积
- `Length()`：长度
- `Normalized()`：归一化

### 三维向量 LVec3

```
LVec3 v = {x, y, z}
```

操作：
- `+`、`-`：向量加减
- `*`、`/`：标量乘除
- `Dot(a, b)`：点积 → 标量
- `Cross(a, b)`：叉积 → 向量
- `Length()`：长度
- `Normalized()`：归一化

### 四维向量 LVec4

常用于齐次坐标和颜色。

```
LVec4 v = {x, y, z, w}
```

## 矩阵 (Matrix)

Lumin 使用 **4×4 列主序矩阵** `LMat4`，内部存储为 `m[col][row]`。

### 变换矩阵

| 函数 | 说明 |
|------|------|
| `Static_Translate(pos)` | 平移矩阵 |
| `Static_Rotate(angle, axis)` | 绕轴旋转矩阵 |
| `Static_Scale(scale)` | 缩放矩阵 |
| `Static_Identity()` | 单位矩阵 |

### 投影矩阵

| 函数 | 说明 |
|------|------|
| `Static_Perspective(fov, aspect, near, far)` | 透视投影 |
| `Static_Ortho(l, r, b, t, n, f)` | 正交投影 |
| `Static_LookAt(eye, center, up)` | 视图矩阵 |

### 矩阵运算

- `A * B`：矩阵乘法（组合变换，从右到左）
- `A * v`：矩阵 × 向量
- `Transposed()`：转置
- `Inverted()`：逆矩阵
- `Data()`：列主序原始数据（OpenGL 直接使用）
- `DataRowMajor(out)`：行主序数据

## 四元数 (Quaternion)

四元数用于表示旋转，避免欧拉角的万向锁问题。

```
LQuat q = {x, y, z, w}
```

- `w = cos(θ/2)`
- `(x, y, z) = sin(θ/2) * axis`

### 创建

| 函数 | 说明 |
|------|------|
| `Static_Identity()` | 无旋转 |
| `Static_FromAxisAngle(axis, rad)` | 绕轴旋转 |
| `Static_FromEuler(pitch, yaw, roll)` | 欧拉角 |

### 运算

| 函数 | 说明 |
|------|------|
| `q1 * q2` | 旋转组合（先q2后q1） |
| `q.RotateVec3(v)` | 旋转向量 |
| `Normalized()` | 归一化 |
| `Conjugate()` | 共轭（逆） |
| `ToMat4()` | 转为旋转矩阵 |
| `Static_Slerp(a, b, t)` | 球面线性插值 |
