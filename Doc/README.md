# Doc

Lumin 引擎文档目录。

## 目录结构

```
Doc/
├── README.md                     # 本文件 - 目录结构说明
├── Lumin架构设计.md               # 引擎架构设计文档（模块划分、属性系统、编辑器设计等）
├── LuminEditor/                  # 编辑器相关文档
│   └── DockWindow.md             # 停靠窗口设计说明
├── Math/                         # 数学库参考文档（可在编辑器帮助菜单中浏览）
│   └── 数学基础.md               # 向量/矩阵/四元数使用说明
└── User/                         # 作者个人文件，维护不及时，请勿作为参考
    ├── Cpp.md
    ├── OpenGLApi.md
    ├── Progress.md
    ├── gltf.md
    ├── vs2022项目分离与依赖.md
    ├── 设计文档.md
    └── 随笔本.md
```

## 说明

- `Lumin架构设计.md` 是项目的主要设计文档，CLAUDE.md 中的架构部分来源于此
- `Math/` 下的 `.md` 文件可通过编辑器 **帮助 → Lumin数学文档** 浏览
- `User/` 为历史遗留文档，内容可能已过时
