二、VS2022 中“项目级依赖”必须先做

这一步非常关键，不做会出现各种链接问题。

1️⃣ 打开解决方案资源管理器

在 VS 的右侧：

Solution 'LuminEngine'
 ├─ EngineCore
 └─ EngineRuntime

2️⃣ 设置项目依赖关系
操作路径（严格照做）

右键解决方案

选择 “项目依赖项…”

在左上角下拉框选择：EngineRuntime

勾选：EngineCore

✔ 表示：EngineCore 必须先构建

3️⃣ 再设置“项目引用”（不是同一个东西）
操作路径

右键 EngineRuntime 项目

添加 → 引用…

勾选：EngineCore

确定

✔ 这一步会自动：

链接 EngineCore.lib

建立 VS 内部引用关系

三、EngineCore 项目必须是 DLL（确认一次）
1️⃣ EngineCore 项目属性
配置类型 → 动态库 (.dll)

路径
右键 EngineCore → 属性
→ 配置属性 → 常规 → 配置类型

2️⃣ 定义导出宏（你之前已经接触过）
EngineCore.h（示例）
#ifdef ENGINECORE_EXPORTS
#define ENGINE_API __declspec(dllexport)
#else
#define ENGINE_API __declspec(dllimport)
#endif

VS 属性中添加宏
C/C++ → 预处理器 → 预处理器定义


加入：

ENGINECORE_EXPORTS


（只在 EngineCore 项目里加）

四、让 EngineRuntime 能 include EngineCore 头文件

这一步是编译期依赖。

1️⃣ 设置 Include 目录
操作路径
右键 EngineRuntime → 属性
→ C/C++ → 常规 → 附加包含目录


添加：

$(SolutionDir)EngineCore\Include


（或者你实际放头文件的路径）

五、链接库一般不用你手动配（如果用了“引用”）

如果你按前面步骤 “添加引用” 做了：

VS 会自动帮你链接 EngineCore.lib

如果你想手动确认：

链接器 → 输入 → 附加依赖项


你应该能看到类似：

EngineCore.lib
